Global Electronics Retail Sales Analysis

Project Overview

An interactive Power BI dashboard analyzing global electronics retail sales, profitability, customer locations, and sales trends.

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

Key Performance Indicators (KPIs)

Metric| Result
Total Sales| 41.91M
Total Profit| 24.52M
Total Orders| 20K
Profit Margin| 58.52%

Key Business Insights

- In-Store sales generated the highest profit.
- Computers were the highest-profit category.
- Sales trends were analyzed over time.
- Online and In-Store performance were compared.

Project Features

- Data cleaning using Power Query
- Data modeling and relationships
- DAX measures and KPI calculations
- Sales and profit analysis
- Customer location visualization
- Time-based sales trend analysis
